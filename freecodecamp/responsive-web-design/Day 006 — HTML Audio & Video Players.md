## What I Learned

### HTML Audio 🎵

I practiced using the `<audio>` element to add sound to a webpage.

I worked with:

- `<audio>`
- `<source>`
- `controls`
- `loop`
- `src`
- `type="audio/mpeg"`

Example:

```html
<audio controls loop>
  <source src="audio/song.mp3" type="audio/mpeg">
</audio>
